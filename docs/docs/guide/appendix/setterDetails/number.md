## Setter Configuration

| Property     | Description                       |
| ------------ | --------------------------------- |
| min, max     | Minimum and maximum values        |
| defaultValue | Default value                     |
| step         | Step size (number)                |
| units        | Unit label (string)               |
| precision    | Number of decimal places (number) |

## Return Type

Number

Returns the `value`.
