## 1. Engine Core Packages

Contains the engine's four core modules: material parsing, orchestration, rendering, and code generation.

Repository: [https://github.com/alibaba/lowcode-engine](https://github.com/alibaba/lowcode-engine)

Sub-packages:

1. designer
2. editor-core
3. editor-skeleton
4. engine
5. ignitor
6. plugin-designer
7. plugin-outline-pane
8. react-renderer
9. react-simulator-renderer
10. renderer-core
11. types
12. utils
13. material-parser
14. code-generator

## 3. Low-Code Plugins

Includes commonly used plugins.

Repository: [https://github.com/alibaba/lowcode-plugins](https://github.com/alibaba/lowcode-plugins)

Sub-packages:

- base-monaco-editor — base code editor
- plugin-code-editor — source code editor panel
- plugin-datasource-pane — data source panel
- plugin-manual — product user manual panel
- plugin-schema — page data panel
- plugin-undo-redo — undo/redo
- plugin-zh-cn — Chinese/English language switch

## 4. Engine Demo

Demonstrates using the engine's orchestration and rendering modules, along with the corresponding dependency resource configuration, in a basic demo.

Repository: [https://github.com/alibaba/lowcode-demo](https://github.com/alibaba/lowcode-demo)

## 5. Toolchain Packages

Includes scaffolding for generating engine ecosystem elements (setters, materials, plugins), startup scripts, debug plugins, and more.

Repository: [https://github.com/alibaba/lowcode-tools](https://github.com/alibaba/lowcode-tools)

## 6. Low-Code Data Source Engine

Implements data source management in both rendering and code-generation runtimes, providing data request capabilities for low-code page building.

Repository: [https://github.com/alibaba/lowcode-datasource](https://github.com/alibaba/lowcode-datasource)

## 7. Base Materials & Material Descriptions

Repository: [https://github.com/alibaba/lowcode-materials](https://github.com/alibaba/lowcode-materials)

## 8. Code Generation Demo

Repository: [https://github.com/alibaba/lowcode-code-generator-demo](https://github.com/alibaba/lowcode-code-generator-demo)
