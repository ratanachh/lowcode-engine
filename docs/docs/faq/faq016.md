---
title: Cannot read property 'Icon' of Undefined
sidebar_position: 16
tags: [FAQ]
---

`@alifd/next` is required for the React canvas and cannot be omitted.

Verify that your asset package includes the following:

```typescript
{
  "title": "Fusion component library",
  "package": "@alifd/next",
  "version": "1.23.0",
  "urls": [
    "https://g.alicdn.com/code/lib/alifd__next/1.23.18/next.min.css",
    "https://g.alicdn.com/code/lib/alifd__next/1.23.18/next-with-locales.min.js"
  ],
  "library": "Next"
},
```
