# Cause

lowcode-engine currently only supports CDN usage. If you created your own project and see this error, it is usually because the npm package was bundled into your build.

# Solution

## engine-demo project

Add [one line to the project's externals configuration](https://github.com/alibaba/lowcode-demo/blob/f8afad0df3190565caccc0a1dfd750dbf84c680f/build.json#L16)
