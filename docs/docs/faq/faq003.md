Background:

- [How to get row data from a button click in an Antd Table?](https://github.com/alibaba/lowcode-engine/issues/341)

## Method 1

![image.png](https://img.alicdn.com/imgextra/i4/O1CN01i58EGG1bxFJBdlS6x_!!6000000003531-2-tps-3342-1126.png)

Following the Fusion ProTable pattern, couple the action column directly with a Button component. Because the `col.render` function receives row data (`record`), the ProTable wrapper can pass `col.render` arguments through to the Button when rendering action column buttons.

## Method 2

Slot + extended parameters

![image.png](https://img.alicdn.com/imgextra/i2/O1CN01pQk2RC1WBXyxjNDif_!!6000000002750-2-tps-3284-1148.png)

Set extended parameters to:

```json
{
  record: this.record,
  index: this.index
}
```

Then the event handler receives them as the second argument:

```json
onClick_new_new(...args){
  console.log(args)
}
```
