---
title: Can Vue Page Code Be Generated?
sidebar_position: 18
tags: [FAQ]
---

The lowcode engine architecture is language-agnostic; with appropriate extensions and plugins, Vue page code can be generated.

If you build pages with the existing React-based Fusion materials but want Vue output at code generation time, you need a Vue material set compatible with Fusion and a custom code generation solution. Replace [these code generation plugins](https://github.com/alibaba/lowcode-engine/blob/main/modules/code-generator/src/solutions/icejs.ts) with ones that target the Vue framework:

![image.png](https://img.alicdn.com/imgextra/i3/O1CN01VxkwCL1l85DiDC2BO_!!6000000004773-2-tps-974-1368.png)

For a detailed customization guide, see [Custom code generation](/site/docs/guide/expand/runtime/codeGeneration#5-custom-code-generation).

If you also want to use Vue materials while building, you need to extend and customize material ingestion, the canvas, the renderer, and related modules. See [Extending the lowcode editor](/site/docs/guide/expand/editor/summary).
