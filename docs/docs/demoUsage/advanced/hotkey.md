---
title: 8. Editor Shortcuts
sidebar_position: 0
---

- Any time:
  - `⌘` `S` Save
  - `⌘` `P` Preview
  - `⌘` `D` View diff
  - `⌘` `Z` Undo
  - `⇧` `⌘` `Z` Redo
- With a component selected:
  - `Backspace` Delete component
  - `⌘` `C` Copy component
  - `⌘` `V` Paste component
  - `⌘` `X` Cut component
  - `⌥` `↑` Move component outward
  - `⌥` `↓` Move component inward
  - `⌥` `←` Move component up among siblings
  - `⌥` `→` Move component down among siblings
  - `↑` Select component above
  - `↓` Select component below
  - `←` Select component to the left
  - `→` Select component to the right
  - `Escape` Clear selection
